# portofolio-V3

Official Portfolio Website of **Arrafi Nur Hafiz** — Full-Stack Developer & Security Enthusiast.

## Visual direction

The portfolio uses a playful, high-contrast visual direction inspired by Slush:
rounded panels, bold display type, pill navigation, bright color blocks, and a
moving introductory ticker. The navigation condenses after scrolling and can
be reopened with its menu button. Decorative hero movement and section reveals
include staggered typography and cards, scroll-linked motion where supported,
and a moving skills marquee. They respect the system reduced-motion preference.
Existing portfolio content and destinations remain the source of truth.

## Tech Stack
- **Framework**: [TanStack Start](https://tanstack.com/start) + [React 19](https://react.dev)
- **Bundler & Tooling**: [Vite](https://vitejs.dev) + [Bun](https://bun.sh)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) + [Lucide Icons](https://lucide.dev)
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Data Fetching**: [TanStack Query](https://tanstack.com/query)

## Quick Start

```bash
# Install dependencies
bun install

# Run development server
bun dev

# Build for production
bun run build
```
